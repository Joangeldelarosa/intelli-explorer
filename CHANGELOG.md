# Changelog

All notable changes to the **Intelli Explorer** extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-12-20

### Added

- **File Hierarchy panel** – standard directory tree showing workspace files and folders.
- **Smart Groups panel** – files automatically grouped by language/type and naming pattern.
- Pattern detection for 40+ naming conventions (controllers, services, models, hooks, etc.).
- Language classification for 30+ file extensions.
- File system watcher with debounced refresh.
- Activity bar icon and sidebar container.
- `Refresh`, `Open File`, and `Reveal in Native Explorer` commands.
